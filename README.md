# wall_stand — настенные элементы для пегборда 28×28 (аналог SKÅDIS)

Набор печатаемых аксессуаров для настенной перфорированной панели
(Wildberries 294532124: 4 панели 28×28 см, сетка 14×7 отверстий).
Модели построены в FreeCAD 1.1 через MCP-сервер `freecad-mcp`
(инструмент `execute_code_headless`), проверены QA-пробами и отрендерены
из того же документа.

## Интерфейс панели и крепёж-крючок

* шаг отверстий: **20 мм** по горизонтали (280/14), **40 мм** по вертикали (280/7);
* отверстие — «ключовина»: круг **Ø5 мм** с прорезью (~2.6–3 мм) **вниз**
  (панель — заявленный аналог IKEA SKÅDIS).

Прямой штифт в круглом отверстии не держится, поэтому весь крепёж —
**крючок-защёлка** (`common.py: mount_pin`):

1. носик **Ø4.8×8 мм** заводится в круг отверстия;
2. держатель сдвигается **вниз на 8 мм** — треугольный язычок (толщина
   **2.4 мм**, длина 8 мм) заходит в прорезь за задней стенкой панели;
3. носик шире прорези и выйти из неё вниз не может — гравитация
   запирает узел. Снятие: поднять на 8 мм и оттянуть от панели.

Требуемый зазор между панелью и стеной ≥ 7 мм (самоклеящиеся держатели
панели его дают). Язычок печатается вертикальной стенкой с наклоном
круче 45° — поддержки не нужны.

## Состав набора (output/stl, печать «стоя», как в сборке)

| файл | что это | крепёж (отверстия) |
|---|---|---|
| `test_mount_fit.stl` | тест: носики Ø4.4/4.6/4.8/5.0 + крючки с язычками 2.2/2.4/2.6/2.8 | — |
| `test_panel_frag.stl` | фрагмент панели с прорезями 2.2–2.8 для подбора пары | — |
| `clip_cable.stl` | клипса для кабеля Ø3–7 (разомкнутое кольцо с пазом) | 2×1 |
| `hook_double.stl` | крючок двойной: два V-кармана с губкой (кабели, ключи) | 2×2 |
| `headband_holder.stl` | держатель наушников (полка 60×42 + губка 14 мм) | 2×2 |
| `small_tray.stl` | лоток 60×55×45 с перфорированным дном | 2×2 |
| `shelf.stl` | полка 150×72 с бортиком 10 мм | 3×2 |
| `basket.stl` | корзина 120×70×55, дно с перфорацией Ø8 | 2×2 |
| `cup.stl` | стакан Ø72×95 для ручек/карандашей | 2×2 |

Число лунок-маркеров на тестах = размер в десятых: 1 лунка → 4.4/2.2,
…, 4 лунки → 5.0/2.8.

## Порядок запуска

1. **Напечатать тесты** `test_mount_fit` + `test_panel_frag`, подобрать
   диаметр носика и ширину язычка под фактическую панель.
2. Если пара отличается от `NOSE_D=4.8`/`TONGUE_W=2.4` — поправить
   `NOSE_D`/`TONGUE_W` в `freecad/common.py` и пересобрать (ниже).
3. Напечатать основные детали.

### Пересборка через FreeCAD MCP

Проект настроен на MCP-сервер `freecad-mcp` (workspace `.zcode/config.json`;
FreeCAD 1.1 на macOS: `/Applications/FreeCAD.app`). Точка входа —
`freecad/build_all.py`, валидация — `freecad/qa_probes.py`; оба
запускаются MCP-инструментом `execute_code_headless` (код-обёртка — в
docstring `build_all.py`). Результат: `output/wall_stand_accessories.FCStd`,
STL (печатная ориентация) и STEP по деталям, таблица валидации в логе.
Превью-картинки: `uv run --with numpy --with matplotlib python render_previews.py`.

## Печать (Bambu Lab A1 mini, PETG)

* стол 180×180×180 — все детали помещаются (макс. полка 150×84×64);
* ориентация — как в STL: деталь «стоит» на нижнем ребре монтажной
  пластины, крючки горизонтальны, печати без поддержек;
* слой 0.2 мм, стенки 3 периметра, заполнение 25–40 % (гирид),
  поддержек нет, кромка (brim) не нужна;
* PETG: сопло 230–250 °C, стол 70–80 °C, обдув 50–80 %;
  для крючков (носики+язычки) желательно 4 периметра — это основная
  нагруженная зона;
* панель держит до 2 кг — не превышайте этот вес на деталь.

## Структура

```
freecad/
  common.py      — параметры (сетка, крючок), построители, реестр деталей
  build_all.py   — сборка FCStd + экспорт STL/STEP + валидация
  qa_probes.py   — функциональные пробы (isInside) по сохранённому документу
  render_previews.py — превью-рендеры STL
  parts/         — по файлу на деталь
output/
  wall_stand_accessories.FCStd, stl/, step/, views/
```
